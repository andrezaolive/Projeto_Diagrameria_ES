# Política de Segurança

## Versões com suporte

O projeto ainda não mantém uma matriz formal de versões suportadas. No momento,
priorizamos relatos que afetem a versão atualmente publicada a partir da branch
`main`. Não há garantia de correções para versões antigas ou forks.

## Como relatar uma vulnerabilidade

**Não publique vulnerabilidades em issues, pull requests ou discussões públicas.**
Use o canal privado de relato de vulnerabilidades do GitHub para este repositório,
se estiver habilitado. Se essa opção não estiver disponível, envie um e-mail para
[projectdiagrameria@gmail.com](mailto:projectdiagrameria@gmail.com) com o assunto
"Relato de segurança — Diagrameria".

Inclua, se possível:

- a parte do projeto afetada e a versão ou commit;
- o impacto observado e os passos mínimos para reproduzir o problema;
- qualquer mitigação conhecida.

Não inclua senhas, tokens, dados pessoais de terceiros ou outros segredos no
relato. Não acesse dados de outras pessoas, não interrompa serviços e não
divulgue publicamente os detalhes enquanto a equipe analisa o caso.

## Tratamento dos relatos

A equipe confirmará o recebimento e, quando necessário, combinará com quem
relatou os próximos passos e a divulgação. Não há um prazo de resposta garantido;
se não receber retorno, você pode acompanhar o relato pelo mesmo canal privado.
