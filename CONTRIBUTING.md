# Como contribuir

Contribuições são bem-vindas por meio de issues e pull requests.

## Antes de começar

- Confira se já existe uma issue relacionada à mudança. Para uma alteração grande ou que mude o comportamento do jogo, abra uma issue para conversar sobre a proposta antes de implementá-la.
- Para mudanças de código, siga as instruções de instalação, testes e lint nos READMEs do [backend](backend/README.md) e do [frontend](frontend/README.md).

## Enviando uma contribuição

1. Crie uma branch a partir de `develop` com um nome que descreva a mudança.
2. Faça alterações focadas e inclua ou atualize testes quando necessário.
3. Execute os testes e verificações relevantes para a parte alterada.
4. Abra um pull request direcionado a `develop`, descrevendo o problema, a solução e como validou a mudança.

Use mensagens de commit claras, em português, seguindo Conventional Commits.
Exemplos:

```text
feat(editor): adiciona ferramenta para criar relacionamentos
fix(conta): corrige salvamento do progresso
docs(readme): atualiza instrucoes para rodar localmente
```

Ao participar, siga o [Código de Conduta](CODE_OF_CONDUCT.md). Para reportar uma vulnerabilidade, não abra uma issue pública; use as orientações em [SECURITY.md](SECURITY.md).
